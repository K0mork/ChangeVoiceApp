# 声のアトリエ

マイクの声をリアルタイムに加工し、スピーカーへ返す iOS アプリです。赤い蝶ネクタイをモチーフにしたオリジナルの操作画面を備えています。

## 操作

- **PITCH**：声の高さを −6〜+6 セミトーンで調整します。
- **TONE**：低域と高域の EQ を反対方向に動かし、声の響きを暖かめから明るめまで調整します。フォルマント変換ではありません。
- **マイクを開始**：タップしたときだけマイク許可を確認し、ライブ音声処理を開始します。
- **変声を停止**：音声入力と出力を停止します。割込み、音声経路の変更、アプリがバックグラウンドに移ったときも停止します。マイク許可の表示中にアプリを離れた場合は、戻ってから開始をもう一度タップしてください。

開始時の出力は小さく設定しています。スピーカーの音がマイクに戻るとハウリングすることがあります。周囲に配慮し、必要に応じてイヤホンをご使用ください。

## ビルド

Xcode で `ChangeVoiceApp.xcodeproj` を開き、iOS 17 以降の iPhone または iPad 向けにビルドしてください。外部ライブラリは使用していません。

## 実機での確認

1. iPhone を Mac に接続し、Xcode でこのプロジェクトを開きます。
2. `ChangeVoiceApp` ターゲットの **Signing & Capabilities** で自分の開発チームを選びます。必要なら Bundle Identifier を自分のものに変更します。
3. 接続した iPhone を実行先に選び、Run を押します。
4. アプリ画面で **マイクを開始** をタップし、表示されたマイク使用許可を選びます。許可はこの操作で初めて要求されます。
5. イヤホンを使って小さい音量から確認します。高さ・響きの調整、停止、アプリを閉じたときの停止を確認します。

Simulator では実機マイクの音質やスピーカーとのハウリングを評価できません。音声処理の確認には実機を使ってください。
