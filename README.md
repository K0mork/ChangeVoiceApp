# 声のアトリエ

マイクの声をリアルタイムに加工し、スピーカーへ返す横向き専用の iOS アプリです。画面全体を深赤の蝶ネクタイ型デバイスに見立てています。

## 操作

- 左のダイヤルで声の高さ（−6〜+6 セミトーン）、右のダイヤルで声の響き（低域・高域の EQ）を調整します。フォルマント変換ではありません。
- アプリを開くとマイク許可を確認し、許可済みの場合は音声処理を始めます。
- 中央のスピーカーアイコンで消音・再開します。割込みや音声経路の変更後は自動再開せず、中央アイコンを押して再開します。
- マイクが許可されていないときは、画面端のマイクアイコンからアプリ設定を開けます。

出力は控えめに設定しています。スピーカーの音がマイクに戻るとハウリングすることがあります。周囲に配慮し、必要に応じてイヤホンをご使用ください。

## ビルド

Xcode で `ChangeVoiceApp.xcodeproj` を開き、iOS 17 以降の iPhone または iPad 向けにビルドしてください。アプリは横向き全画面で動作します。外部ライブラリは使用していません。

## 実機での確認

1. iPhone を横向きにして Mac に接続し、Xcode でこのプロジェクトを開きます。
2. `ChangeVoiceApp` ターゲットの **Signing & Capabilities** で自分の開発チームを選びます。必要なら Bundle Identifier を自分のものに変更します。
3. 接続した iPhone を実行先に選び、Run を押します。
4. アプリを開いたときに表示されたマイク使用許可を選びます。許可すると音声処理が始まります。
5. イヤホンを使って小さい音量から確認します。左右ダイヤル、中央の消音・再開、バックグラウンド移行後の再開を確認します。

Simulator では実機マイクの音質やスピーカーとのハウリングを評価できません。音声処理の確認には実機を使ってください。

## 確認記録（2026-10-07）

- iPhone 18 Pro（iOS 27）Simulator でビルド、インストール、起動し、マイク権限を拒否した状態で横向き画面を確認しました。音声処理は起動していません。
- ダイヤル操作と許可後の消音操作、および実機での音質・遅延・ハウリングは未確認です。
